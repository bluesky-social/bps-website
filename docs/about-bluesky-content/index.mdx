This docs site contains everything you need to understand Bluesky the [app](https://bsky.social/about) and Bluesky's own infrastructure services. If Bluesky were just an app and not a gateway to the [AT Protocol ecosystem](https://atproto.com/guides/understanding-atproto) (also called the Atmosphere), these would be comprehensive docs.

There's lots more to discover in the Atmosphere, though, including [tutorials](https://atproto.com/guides/tutorials), [the atproto stack](https://atproto.com/guides/the-at-stack), and a [developer blog](https://atproto.com/blog). For all of that, refer to [atproto.com](https://atproto.com). This site covers Bluesky Protocol Services, a Getting Started guide for new devs, and a deep dive into how content works on Bluesky.

## Handling content

The pages below dig into how Bluesky represents the content people post — videos, the underlying shape of a post record, the rich-text facets that power links and mentions, and how to handle timestamps in a distributed network. The last two cover how Bluesky content travels off the app — through embeds on other sites, and intent links that hand off to the compose UI.
