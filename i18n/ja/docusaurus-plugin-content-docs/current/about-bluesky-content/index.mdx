# Blueskyのコンテンツについて

このドキュメントサイトには、Blueskyの[アプリ](https://bsky.social/about)とBlueskyのインフラストラクチャサービスを理解するために必要な情報がすべて掲載されています。Blueskyが[AT Protocolエコシステム](https://atproto.com/guides/understanding-atproto)（Atmosphereとも呼ばれます）への入り口ではなく、単なるアプリであるならば、これらはすべてを網羅するドキュメントとなるでしょう。

ただし、Atmosphereには[チュートリアル](https://atproto.com/guides/tutorials)、[atprotoスタック](https://atproto.com/guides/the-at-stack)、[開発者ブログ](https://atproto.com/blog)など、まだまだ多くの情報があります。これらについては[atproto.com](https://atproto.com)を参照してください。本サイトでは、Bluesky Protocol Services、新規開発者向けの「はじめに」ガイド、そしてBluesky上でコンテンツがどのように扱われるかの詳細を取り上げます。

## コンテンツの取り扱い

以下のページでは、Blueskyが投稿コンテンツをどのように表現しているかを掘り下げます。動画、投稿レコードの基本構造、リンクやメンションを支えるリッチテキストのファセット、そしてクロックがずれ得る分散ネットワークでタイムスタンプをどのように扱うかなどを取り上げます。最後の2つは、Blueskyのコンテンツがアプリの外でどのように流通するか（他サイトへの埋め込みや、作成UIへ受け渡しを行うインテントリンク）について解説します。

- [動画のアップロード](/docs/about-bluesky-content/video) — 画像との違い、処理時間、アップロードフローを含めた動画アップロードの仕組み。
- [投稿の詳細](/docs/about-bluesky-content/posts) — 投稿作成の裏側を覗き見る。
- [リンク・メンション・リッチテキスト](/docs/about-bluesky-content/post-richtext) — リッチテキストファセットが投稿テキストにリンクやメンションなどをどのように注釈付けするか。
- [タイムスタンプ](/docs/about-bluesky-content/timestamps) — クロックがずれ得る分散ネットワークでタイムスタンプを生成・解釈するための指針。
- [スレッドゲート](/docs/get-started/thread-gates) — 投稿への返信権限を設定する。
- [埋め込み](/docs/oembed) — HTMLスニペットとoEmbed APIを使って、他のウェブサイトにBluesky投稿を埋め込む方法。
- [アクションインテントリンク](/docs/intent-links) — 外部サイトからBlueskyの作成UIをあらかじめ埋めて、「Blueskyでシェア」ボタンを実現する。
